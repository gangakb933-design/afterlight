# Project Afterlight

**Team Echonova** · NASA Space Apps Challenge 2026

**Abandoned, but not forgotten.** A mobile-friendly educational website for the NASA Space Apps Challenge 2026 challenge *"Abandoned but Not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars."*

Live site: https://gangakb933-design.github.io/afterlight/

## What it is
Six missions told as short stories: **Apollo 11**, **Surveyor 3**, **Opportunity**, **Spirit**, **Sojourner** and **Voyager 1** (included as a contrast: it is not abandoned).

## Features
- Mission pages with a real NASA photo, quick facts, key numbers and expandable evidence cards
- **Story mode**: a full-screen scroll-through story for each mission
- **Listen** button that reads each mission aloud (browser text-to-speech)
- Tap-to-zoom photo viewer with captions and credits
- 4-question quiz per mission and an **Explorer Passport** (stamps saved in the browser, printable certificate after all six)
- Timeline (1967 to 2019), landing-site map, glossary and credits page
- Keyboard accessible, reduced-motion friendly, works on phones

## How it is built
A single `index.html` (HTML, CSS and JavaScript, no framework or build step) plus six photos. Hosted free on GitHub Pages.

## Sources and credits
Facts come from NASA mission pages (linked at the bottom of each mission). Photos are NASA images; exact IDs and credit lines are on the site's Credits page. This is an independent project and is **not affiliated with or endorsed by NASA**.

## AI tools
The website code and text were written with help from an AI assistant (Claude by Anthropic). Facts were checked against NASA sources by the author.
